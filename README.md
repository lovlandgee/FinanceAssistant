# Проект Personal Finance Manager — AI Assistant (на основе GigaChat)

Пилотный вариант веб-приложения на **Streamlit** для анализа личных финансов по **CSV-выписке** из банка (на данный момент используются mock-данные, приложенные к проекту): статистика, графики, поиск аномалий, правила-советы и опциональные рекомендации от **GigaChat** (только по агрегированным данным, без сырой таблицы операций).

## Возможности

- Загрузка CSV с лимитами по размеру и числу строк
- Автоопределение разделителя (`,` / `;` / таб) и кодировки UTF-8
- Ручное сопоставление колонок (дата, сумма, категория, описание), если банк использует нестандартные заголовки
- Гибкий разбор сумм (пробелы, запятая/точка как десятичный разделитель)
- Доходы и расходы, динамика по месяцам, структура по категориям
- Выделение подозрительных трат (Isolation Forest)
- Блок советов на основе эвристик
- **GigaChat** по безопасному JSON-payload (KPI, помесячные итоги, топ категорий, счётчик аномалий, краткие rule-based советы)

## Стек

- Python 3.10+
- Streamlit, Pandas, NumPy, Plotly, scikit-learn
- `gigachat` (официальный клиент)


## GigaChat 

Получите учётные данные в экосистеме GigaChat и задайте переменную окружения:

```bash
export GIGACHAT_CREDENTIALS="ваш_ключ_авторизации"
```

В боковой панели включите **«Включить AI-рекомендации»** и при необходимости смените модель в списке.

## Запуск

```bash
streamlit run app.py
```

Откроется страница в браузере: загрузите CSV-файл (либо один из приложенных к проекту, либо создайте свой mock.csv) и при необходимости укажите соответствие колонок.

## Формат CSV

**Обязательно:**

- колонка с **датой** (например `дата`, `date`, …)
- колонка с **суммой** (например `сумма`, `amount`, …)

**Соглашение по знаку суммы:** расходы — **отрицательные** числа, доходы — **положительные**.

**Опционально:** категория, описание.

Если категории в интерфейсе показываются как `Unknown`, в блоке **«Сопоставление колонок»** выберите столбец **«Колонка с категорией»** — значение по умолчанию **«(нет)»** отключает категории.

Пример готового файла: `sample_transactions_ru.csv` (заголовки: `дата`, `сумма`, `категория`, `описание`).

## Конфиденциальность и ИИ

В модель **не отправляется** полный CSV и построчные описания операций. В запрос уходит только **агрегированная** статистика (см. `build_llm_payload` в `app.py`).

## Ограничения

- Схемы выписок у банков различаются — при необходимости расширьте `COLUMN_ALIASES` в `app.py`.
- Советы и ответы LLM носят **ознакомительный** характер, не являются персональной финансовой консультацией.
